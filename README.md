# Dashboard

React 19 + Vite + Tailwind CSS v4 asosida qurilgan dashboard to'plami.
`main` branchda faqat umumiy skelet turadi, har bir dizayn alohida branchda:

| Branch | Ko'rinish |
| --- | --- |
| `design/minimal-light` | Minimalist och SaaS analytics paneli |
| `design/dark-neon` | Qorong'i neon / crypto trading paneli |
| `design/glass-aurora` | Glassmorphism + aurora gradient |
| `design/neo-brutal` | Neo-brutalist, qalin chegara va qattiq soya |
| `design/dense-admin` | Zich korporativ admin paneli |

## Ishga tushirish

```bash
npm install
npm run dev
```

Boshqa dizaynni ko'rish:

```bash
git checkout design/dark-neon
npm run dev
```

Grafiklar tashqi kutubxonasiz, qo'lda yozilgan SVG komponentlar.
